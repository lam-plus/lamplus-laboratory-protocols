# HSI scanning system

[Português brasileiro](README.pt-BR.md)

The complete HSI system may include FX10 and SWIR cameras, illumination, translation stage, reference targets, control software, calibration, acquisition, and data handling. The cameras are components of the integrated system.

Technical protocols will be added and validated progressively. No operating protocol is approved in this initial scaffold.

System identifier namespace: `LAM-HSI-###`.
