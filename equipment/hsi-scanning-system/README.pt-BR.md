# Sistema de varredura hiperespectral (HSI)

[English](README.md)

O sistema HSI completo pode incluir câmeras FX10 e SWIR, iluminação, estágio de translação, alvos de referência, software de controle, calibração, aquisição e tratamento de dados. As câmeras são componentes do sistema integrado.

Os protocolos técnicos serão adicionados e validados progressivamente. Nenhum protocolo operacional está aprovado nesta estrutura inicial.

Identificadores reservados ao sistema: `LAM-HSI-###`.
