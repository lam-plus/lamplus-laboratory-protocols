# Contributing / Como contribuir

## English

Welcome! Thank you for helping improve the public laboratory protocols of LAM+, Universidade Federal Fluminense.

### Contributions welcome

- Technical or editorial corrections and improvements to existing protocols.
- Translation and bilingual review.
- Corrections to links, images, and references.
- Proposals for new protocols.
- Improvements to templates and the Pandoc/PDF workflow.

Open a GitHub issue before making major changes or creating a new protocol to discuss scope and approach with the maintainers.

### Workflow

1. Fork the repository.
2. Create a branch for your contribution.
3. Edit the relevant files, following [AGENTS.md](AGENTS.md) and the shared [templates](templates/).
4. Check links and images, generate PDFs for affected protocols in both languages, and inspect the results.
5. Open a pull request describing the changes, their rationale, and the checks performed.

### Conventions

- Write protocols in Markdown, with separate English (`.md`) and Brazilian Portuguese (`.pt-BR.md`) files. Keep translations, identifiers, versions, dates, and technical content synchronized.
- Store protocol images in the corresponding equipment's `assets/` directory, using `common/`, `en/`, or `pt-BR/` as appropriate. Use relative image paths and record sources and permissions in `IMAGE_CREDITS.md`.
- Explain any changes to original data or image files. Do not add research data, personal data, confidential information, or sensitive material to this public repository.
- Maintain Pandoc compatibility. Edit Markdown sources, not generated PDFs.

### Scientific review and AI use

External contributions are welcome. Incorporation depends on technical and scientific review by LAM+; maintainers may request changes before merging.

AI tools may support writing, translation, organization, and maintenance. A person must verify all technical and scientific content, and the contributor remains responsible for the submitted content. Do not enter confidential information, personal data, or materials with usage restrictions into external tools.

## Português brasileiro

Boas-vindas! Agradecemos sua colaboração para melhorar os protocolos laboratoriais públicos do LAM+, Universidade Federal Fluminense.

### Contribuições bem-vindas

- Correções técnicas ou editoriais e melhorias em protocolos existentes.
- Tradução e revisão bilíngue.
- Correção de links, imagens e referências.
- Propostas de novos protocolos.
- Melhorias nos templates e no processo Pandoc/PDF.

Abra uma issue no GitHub antes de realizar mudanças grandes ou criar um novo protocolo para discutir o escopo e a abordagem com os mantenedores.

### Fluxo de contribuição

1. Crie um fork do repositório.
2. Crie uma branch para sua contribuição.
3. Edite os arquivos pertinentes, seguindo [AGENTS.md](AGENTS.md) e os [templates](templates/) compartilhados.
4. Verifique links e imagens, gere os PDFs dos protocolos afetados nos dois idiomas e inspecione os resultados.
5. Abra um pull request descrevendo as alterações, sua justificativa e as verificações realizadas.

### Convenções

- Escreva os protocolos em Markdown, com arquivos separados em inglês (`.md`) e português brasileiro (`.pt-BR.md`). Mantenha traduções, identificadores, versões, datas e conteúdo técnico sincronizados.
- Armazene as imagens dos protocolos na pasta `assets/` do equipamento correspondente, usando `common/`, `en/` ou `pt-BR/`, conforme o caso. Use caminhos relativos para imagens e registre fontes e autorizações em `IMAGE_CREDITS.md`.
- Explique qualquer alteração em arquivos originais de dados ou imagens. Não adicione dados de pesquisa, dados pessoais, informações confidenciais ou materiais sensíveis a este repositório público.
- Mantenha a compatibilidade com Pandoc. Edite as fontes em Markdown, não os PDFs gerados.

### Revisão científica e uso de IA

Contribuições externas são bem-vindas. A incorporação depende de revisão técnica e científica pelo LAM+; os mantenedores podem solicitar alterações antes do merge.

Ferramentas de IA podem apoiar redação, tradução, organização e manutenção. Todo conteúdo técnico e científico deve ser verificado por uma pessoa, e quem submete a contribuição permanece responsável pelo conteúdo. Não insira informações confidenciais, dados pessoais ou materiais com restrição de uso em ferramentas externas.
