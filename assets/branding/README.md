# Institutional branding / Identidade institucional

Reserved for authorized LAM+ and UFF branding. No logos are supplied or required for PDF builds. Record source, rights holder, date, license or permission, and usage restrictions here before adding assets. Documentation licensing does not grant rights to institutional marks.

Reservado à identidade visual autorizada do LAM+ e da UFF. Nenhum logotipo é fornecido ou exigido para gerar PDFs. Registre aqui a fonte, titular, data, licença ou autorização e restrições de uso antes de adicionar arquivos. A licença da documentação não concede direitos sobre marcas institucionais.

The PDF template accepts optional `lam-logo` and `uff-logo` metadata with repository-relative image paths. Missing files are skipped. Prefer PDF or PNG for XeLaTeX.
O modelo PDF aceita os campos opcionais `lam-logo` e `uff-logo` com caminhos relativos ao repositório. Arquivos ausentes são ignorados. Prefira PDF ou PNG para XeLaTeX.
